# 报价系统流程

## 使用场景

当客户发来汽车线索、到店、成交、保单等询价需求时，运营和渠道同事在报价系统中统一记录需求口径、录入方式、判定标准、上游报价、自有渠道或产能中心报价，并沉淀最终建议报价。

## 操作步骤

1. 进入左侧菜单「报价系统」。
2. 点击「新增询价」，填写客户名称、需求联系人、询价时间、城市、品牌、车型、需求类型和需求量级。
3. 在「录入、下发与判定规则」中确认客户要求：
   - 是否需要平安保单。
   - 是否支持精准下发。
   - 是表格录入、链接录入、二维码录入还是其他方式。
   - 如果是二维码，是否可以转链接并开白名单。
   - 是否需要接收验证码。
   - 是否要求成交、成交比例、是否要求到店。
   - 判定标准是系统判定、我方凭证、客户判定还是混合判定。
4. 在「报价与量级」中分别记录上游报价、自有渠道或产能中心报价、各自可承接量级和建议对外报价。
5. 保存后，在列表中查看风险标签，例如「二维码未白名单」「需验证码」「需成交」「需到店」「需平安保单」。
6. 根据进展流转状态：新询价 → 需求确认中 → 询价中 → 已报价 → 已中标/未中标 → 已归档。
7. 点击客户名称进入详情抽屉，复核需求规则、报价对比、风险标签和下一步动作。

## 注意事项

- 客户没有给价格时，客户给价填 0，并保持「需要报价」。
- 二维码录入如果不能转链接开白名单，应提前确认验证码、人工作业和录入失败成本。
- 成交或到店类需求必须写清判定标准，避免后续对账时口径不一致。
- 上游报价和自有报价都可以为空，但建议报价前至少确认一种可承接量级。
- 预计毛利率用小数填写，例如 25% 填 `0.25`。

## 常见问题

### 客户只发了车型和城市，没有价格怎么办？

新增询价时勾选需要报价，客户给价填 0，状态先保持「新询价」或「需求确认中」，待上游或自有渠道反馈后再补报价。

### 上游和自有渠道都能做，怎么记录？

分别填写上游报价/量级和自有或产能中心报价/量级，在报价备注中写明推荐承接方案，例如「上游主供，自有补量」。

### 如何判断是否可以对外报价？

至少需要明确城市、车型、量级、录入方式、是否需要验证码、是否要求成交/到店、判定标准和一种可承接报价。
