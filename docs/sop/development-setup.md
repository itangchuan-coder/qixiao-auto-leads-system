# 开发环境搭建 SOP

## 使用场景

第一次在本机启动项目，或换电脑后重新搭建环境。

## 操作步骤

1. 打开项目目录。
2. 确认 Node.js 可用：`node -v`。
3. 确认 pnpm 可用：`pnpm -v`。
4. 安装依赖：`pnpm install`。
5. 启动开发服务：`pnpm dev`。
6. 根据终端提示打开本地地址。

## 注意事项

- 当前第一版是前端原型，不需要数据库。
- 如果端口被占用，Vite 会自动提示新的端口。
- 修改代码后浏览器会自动刷新。

## 常见问题

- 依赖安装失败：先确认网络可访问 npm registry。
- 页面空白：查看终端和浏览器控制台报错。
- 命令不存在：优先安装 Node.js 和 pnpm。
