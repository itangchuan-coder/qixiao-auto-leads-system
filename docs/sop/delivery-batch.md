# 交付批次 SOP

## 使用场景

将一批有效线索交付给平台或主机厂，并记录交付对象、数量和状态。

## 操作步骤

1. 进入“线索管理”页面。
2. 筛选状态为“有效”的线索。
3. 勾选要交付的线索。重复、无效和已交付线索不可勾选。
4. 点击“创建交付批次”。
5. 选择交付对象。
6. 填写备注，例如筛选条件、交付口径、对账说明。
7. 确认创建批次。
8. 在线索列表确认相关线索状态变为“已交付”。
9. 在“交付批次”页面查看批次记录。

## 注意事项

- 第一版支持模拟导出 Excel。
- 批次创建后，线索状态会流转为已交付。
- 创建时系统会再次校验所选线索；即使保留了旧勾选，非有效线索也不能写入批次。
- 后续真实系统需要增加导出留痕和对账状态。

## 常见问题

- 无法创建批次：确认已勾选状态为“有效”的线索；其他状态不能交付。
- 找不到交付对象：先到“交付对象”页面新增。
- 批次数量不对：检查筛选条件和勾选记录。
