# 成交开拓基地 SOP

## 使用场景

成交开拓中心运营通过自有外呼中心联系主机厂各城市经销商门店，获取可成交产能，并记录预占量级、付款交割和成交结果。

## 操作步骤

1. 进入“成交开拓基地”页面。
2. 点击“新增产能”。
3. 填写城市、主机厂品牌、经销商门店、联系人、电话和职位。
4. 填写供应车型、供应内容、供应凭证和供应时间。
5. 判断是否有效，记录量级。
6. 填写付款方式、金额、我司对接人、我司付款人和付款时间。
7. 按实际进度流转状态：
   - 待联系
   - 已建立联系
   - 可供应
   - 已预占
   - 已交割
   - 成交成功 / 成交失败
8. 如果成交失败，填写失败原因。
9. 如果客户不算成交且成本由公司负担，标记“成本公司承担”。

## 注意事项

- 供应凭证第一版先用截图编号、录音编号、链接或文字说明记录。
- 成交产能状态只能通过列表或详情中的状态流转操作推进；编辑记录不会改变状态。
- 城市、主机厂品牌和供应车型支持中文、拼音全拼、拼音首字母搜索。
- 如果没有对应城市、品牌或车型，可以直接输入后选择“手动添加”。
- 预付且未成交的记录要重点跟进，避免成本无法核销。
- 成交失败要写明原因，例如客户不算成交、车型不匹配、经销商不认定。
- 后续可以把客户需求/线索与成交产能打通，形成需求匹配和成交率统计。

## 常见问题

- 状态按钮不可用：检查当前角色是否为管理员或运营。
- 无法判断是否有效：先记录为待联系或已建立联系，不要提前标记可供应。
- 成本是否公司承担不确定：先在备注中记录原因，等待财务或负责人确认。
