# 登录工作台流程

## 使用场景

内部用户从 `/login` 进入启效智联线索管理系统，使用企业账号进入工作台。

## 操作步骤

1. 线上 Supabase 已配置时，输入企业邮箱；未配置的本地原型仍可使用演示账号流程。
2. 输入登录密码，可勾选“保持登录”。
3. 点击“进入工作台”，验证通过后返回系统首页。
4. 忘记密码时点击提示，联系系统管理员处理。

## 注意事项

- 设置 `VITE_SUPABASE_URL` 和 `VITE_SUPABASE_PUBLISHABLE_KEY` 后，页面使用 Supabase Auth 校验邮箱、密码和登录态。
- 未设置上述变量时，系统保留原型模式，便于不连接线上服务的本地演示。
- 前端不得保存明文密码；服务端密钥只能在 Supabase 管理端或 CI/CD Secret 中使用。
- 登录成功后，系统从 `organization_members` 读取真实角色，线上模式不可通过页面切换角色。
- 右上角用户设置支持验证当前密码后修改新密码；管理员无法查看原密码。
- 忘记密码时联系超级管理员，由权限后台按邮箱设置临时密码；用户登录后必须立即在账户设置中修改密码。

## 常见问题

### 账号无法登录怎么办？

确认企业邮箱和密码均已填写；仍无法登录时联系管理员邀请或重置账号。

### 用户自己修改密码

1. 登录后点击右上角用户名称，进入“账户设置”。
2. 输入当前密码、新密码和确认密码。
3. 点击“修改密码”，成功后使用新密码重新登录。

### 管理员重置用户密码

1. 管理员打开“权限与账号管理”。
2. 点击“重置用户密码”，填写用户邮箱和临时密码。
3. 通过安全渠道把临时密码交给用户，不要在群聊或公开文档中记录。
4. 用户登录后立即进入账户设置修改为个人密码。
