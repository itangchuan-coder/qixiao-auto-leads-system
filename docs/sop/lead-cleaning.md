# 线索清洗与去重 SOP

## 使用场景

运营确认线索是否有效、是否重复、是否可以交付。

## 操作步骤

1. 进入“线索管理”页面。
2. 查看状态为“待清洗”或“重复”的线索。
3. 核对手机号、城市、意向品牌、车型和备注。
4. 对有效线索改为“有效”。
5. 对重复线索保留质量更高的一条，另一条标记为“重复”或“无效”。
6. 对无效线索标记为“无效”并写明原因。
7. 每次关键判断后，在详情页添加跟进记录，说明判断依据。

## 注意事项

- 管理员和运营可以看到完整手机号。
- 其他角色默认只看脱敏手机号。
- 清洗动作要尽量保留备注，方便后续复盘。
- 状态变化会自动生成跟进记录，人工沟通内容也要及时补充。

## 常见问题

- 同一手机号不同车型：优先保留最新或信息最完整的记录。
- 城市缺失：先标记待清洗，不直接交付。
- 来源不明：备注中记录“来源待确认”。
