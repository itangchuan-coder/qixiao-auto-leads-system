## 维护规则

- 每新增一个核心业务模块，同步新增或更新 SOP。
- 每个 SOP 都要包含使用场景、操作步骤、注意事项、常见问题。
- 真实流程变化后，先更新系统，再更新 SOP，最后运行发布前检查。
