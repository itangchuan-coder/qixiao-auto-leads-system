# SOP 下载与发布流程

## 使用场景

运营、主管和其他角色需要下载与自身权限匹配的 SOP；主管需要发布新版 SOP。

## 操作目的

- 让执行人员只获取与岗位相关的流程文档。
- 让 SOP 更新有明确发布人、版本号、适用范围和发布时间。
- 避免通过聊天记录或本地文件传播失效版本。

## 下载 SOP

1. 进入左侧菜单「流程/SOP」。
2. 系统根据当前角色展示可下载的 SOP：
   - 运营：运营岗位 SOP、通用说明。
   - 主管：主管岗位 SOP、运营岗位 SOP、通用说明。
   - 其他角色：通用说明。
   - 管理员：可下载全部已发布 SOP。
3. 点击目标 SOP 右侧的「下载」，浏览器保存 Markdown 文件。
4. 执行工作时以最新版本号和更新时间为准。

## 主管上传并发布 SOP

1. 以主管或管理员角色进入「流程/SOP」。
2. 点击「上传发布」。运营和其他角色不会显示此入口。
3. 填写 SOP 名称、适用角色和版本号。
4. 上传 `.md` 或 `.txt` 格式的 SOP 文件。
5. 点击确认，检查发布成功提示，并切换到目标角色复核该 SOP 是否可见和可下载。

## 注意事项

- 当前原型只在浏览器会话中保存新发布的 SOP；刷新页面后恢复预置版本。正式上线前需要接入对象存储、版本库、审批记录和持久化权限服务。
- 新版本发布前应说明生效日期、替代的旧版本和变更范围。
- SOP 不得包含账号密码、客户完整手机号、合同原件或其他敏感信息。
- 误发布时，当前原型无法撤回；先停止使用并由主管重新发布修订版本。

## 常见问题

### 为什么看不到上传发布？

检查右上角角色。只有主管和管理员可发布 SOP。

### 为什么下载列表没有某份 SOP？

确认该文档的适用角色。运营和其他角色仅能看到其权限范围内的版本。
