# 业务助手使用流程

## 使用场景

登录后，点击顶部的“业务助手”，可以用自然语言查询业务情况或获取当前页面的操作指引。

## 操作步骤

1. 在任意业务页面点击顶部“业务助手”。
2. 点击快捷问题，或直接输入一句需求，例如“查看我今天待跟进的线索”。
3. 先阅读助手说明；查询类操作会返回结果，修改类操作必须等待确认卡片。
4. 确认卡片会清楚列出即将变更的数据；核对无误后再点击确认。

## 注意事项

- 查询类请求会真实读取当前用户有权限访问的 Supabase 数据。
- “新增跟进记录”会先显示确认卡片；只有点击“确认执行”才写入，取消则不产生数据。
- 删除、批量修改、交付、报价确认和权限调整目前不会执行。
- DeepSeek Key 只保存在 Cloudflare Worker Secret 中，不要输入助手对话框。
- 不要向对话框输入密码、验证码、Supabase 密钥或其他敏感凭证。
