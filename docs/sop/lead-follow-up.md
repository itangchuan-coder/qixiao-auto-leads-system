# 线索搜索、状态流转与跟进 SOP

## 使用场景

运营需要快速找到线索、推进线索状态，并记录每次沟通或处理结果。

## 操作步骤

1. 进入“线索管理”页面。
2. 在筛选区输入关键词，可按姓名、手机号、城市、品牌、来源查询。
3. 城市、品牌和车型相关字段支持中文、拼音全拼、拼音首字母搜索。
4. 如果选项中没有目标城市、品牌或车型，可以直接输入后选择“手动添加”。
5. 按需要选择线索状态，缩小待处理范围。
6. 在线索表格中点击客户姓名，打开详情页。
7. 在“状态流转”区域选择下一步状态：
   - 新线索 → 待清洗
   - 待清洗 → 有效 / 重复 / 无效
   - 有效 → 已交付 / 无效
8. 在“跟进记录”区域填写沟通内容、清洗判断或异常说明。
9. 保存后查看时间线，确认记录已经进入该线索详情。

## 注意事项

- 状态流转必须由管理员或运营操作。
- 其他角色只能查看脱敏信息，不能推进流程。
- 跟进记录要写清楚事实依据，不只写“已处理”。
- 已交付和无效状态通常是流程终点，后续如需重启流程再单独设计。
- 后续涉及城市、主机厂、品牌、车型的字段，默认使用智能选择，不再使用普通输入框。

## 常见问题

- 搜不到线索：先清空筛选条件，再按手机号或姓名搜索。
- 状态按钮不可用：检查右上角当前角色是否为管理员或运营。
- 跟进记录没显示：确认详情页里点击了“添加跟进”。
