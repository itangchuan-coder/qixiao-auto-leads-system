# 页面开发流程 SOP

## 使用场景

新增或修改一个后台页面，例如线索管理、交付批次、工作台。

## 操作步骤

1. 明确页面目标：这个页面解决什么业务问题。
2. 明确字段和按钮：哪些信息要展示，哪些动作要操作。
3. 在 `src/domain/types.ts` 补充业务类型。
4. 在 `src/domain/mockData.ts` 补充模拟数据。
5. 优先把默认值、选项配置、状态流转规则放到独立 domain 文件，不要全部堆在 `src/App.tsx`。
6. 在 `src/App.tsx` 增加菜单和页面渲染。
7. 使用 Ant Design 的表格、表单、弹窗、抽屉等组件。
8. 运行 `pnpm build` 检查类型和构建。
9. 更新对应 SOP。

## 注意事项

- 第一版优先做可点击原型，不急着接真实接口。
- 表格字段不要一次做太多，先保证核心流程清楚。
- 按钮权限要考虑管理员、运营、其他角色。

## 常见问题

- 字段显示不一致：检查类型、mock 数据和表格列是否使用同一字段名。
- 页面太乱：优先拆成列表、详情、弹窗三个区域。
- 操作无反馈：用 Ant Design 的 message 或 Alert 给用户反馈。
