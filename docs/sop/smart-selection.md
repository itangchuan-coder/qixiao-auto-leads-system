# 城市、品牌、车型智能选择 SOP

## 使用场景

所有涉及中国城市、在华销售主机厂/品牌、车型的字段，都使用智能选择组件，避免普通文本输入导致名称不统一。

## 操作步骤

1. 点击城市、品牌或车型选择框。
2. 可以输入中文，例如“上海”“问界”“问界 M9”。
3. 可以输入拼音全拼，例如 `shanghai`、`wenjie`。
4. 可以输入拼音首字母，例如 `sh`、`wj`。
5. 车型可以输入英文或数字关键词，例如 `m9`、`model y`、`byd`。
6. 如果列表没有目标项，继续输入完整名称，选择“手动添加”。

## 注意事项

- 第一版内置常用中国城市和主流在华销售品牌车型，不追求一次覆盖所有车型。
- 手动添加的数据当前只进入本次表单值，不等于正式维护进基础库。
- 后续可以升级为品牌车型库管理、Excel 导入品牌车型库、主机厂-品牌-车型联动。

## 常见问题

- 搜不到：先尝试中文、拼音全拼、首字母或车型数字。
- 名称不规范：优先选择已有选项，少用手动添加。
- 新车型较多：后续应建立车型基础库维护页面。
