# 线索导入 SOP

## 使用场景

运营从 Excel 批量导入汽车销售线索。

## 操作步骤

1. 准备 Excel 字段：姓名、手机号、城市、意向品牌、意向车型、预算、购车时间、来源、备注。
2. 进入系统的“线索导入”页面。
3. 上传 Excel 文件。
4. 查看导入结果：成功数量、重复数量、失败数量。
5. 对重复线索进入清洗流程。
6. 对成功线索进入线索管理列表。

## 注意事项

- 当前第一版是模拟导入，不真实解析 Excel。
- 手机号是判断重复线索的核心字段。
- 后续接真实导入时，要保留导入结果明细，方便追溯。

## 常见问题

- 重复线索过多：先检查来源是否重复提交。
- 字段缺失：要求导入表格使用统一模板。
- 手机号格式错误：后续真实版本需要加入格式校验。
