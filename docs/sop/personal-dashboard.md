# 个人业务驾驶舱流程

## 使用场景

个人业务驾驶舱用于个人查看自己当前负责的客户项目、报价任务、成交产能事项、项目金额、账期提醒、付款与垫付风险，以及个人任务完成进度。

## 操作步骤

1. 进入左侧菜单「个人业务驾驶舱」。
2. 在右上角「查看个人」中选择自己的姓名。
3. 查看顶部指标卡：
   - 负责项目：当前个人作为销售或运营负责的项目数量。
   - 项目金额：负责项目的最终结算金额合计。
   - 待收/未到账：未到账首付款金额。
   - 垫付风险：预付且尚未成交成功的成交产能金额。
4. 查看「个人任务完成进度」，确认客户项目、报价任务和成交产能事项的总体完成比例。
5. 查看「账期提醒」，重点关注账期较长、未结算或首付款未到账的项目。
6. 查看「付款与垫付关键信息」，优先处理未到账首付和预付未成交事项。
7. 在「我负责的项目」和「我的报价任务」中点击项目或报价名称，进入详情抽屉继续处理。

## 自动统计口径

- 客户项目：匹配销售负责人或运营负责人等于当前选择个人。
- 报价任务：匹配销售负责人、运营负责人或渠道负责人等于当前选择个人。
- 成交产能：匹配我司对接人或我司付款人等于当前选择个人。
- 项目金额：汇总客户项目中的最终结算总金额。
- 待收/未到账：汇总首付款未到账项目的首付款金额。
- 垫付风险：汇总预付且尚未成交成功的成交产能金额。
- 任务进度：按客户项目完成/结算、报价已报价/中标/未中标/归档、成交产能成功/失败计算。

## 注意事项

- 驾驶舱是自动统计页，不需要手动保存。
- 如果某个项目未出现在驾驶舱，请先检查项目、报价或产能记录里的负责人姓名是否一致。
- 金额和账期提醒依赖客户项目中的结算金额、首付款和账期字段，需要在项目管理里及时维护。
- 垫付风险依赖成交开拓基地中的付款方式、金额和成交结果，需要在成交产能流转后及时更新状态。

## 常见问题

### 为什么任务进度不是 100%？

只要仍有执行中的客户项目、未完成报价或未完成成交产能事项，进度就不会达到 100%。

### 为什么账期提醒里出现已完成项目？

已完成但未结算的项目仍需要跟进账期和付款，只有状态进入「已结算」后才会从账期提醒中移除。
